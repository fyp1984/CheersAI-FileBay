# 生产知识库 MVP 验收标准

## 自动化门禁

1. `go test -tags "sqlite sqlite_unlock_notify" ./models/knowledge ./services/knowledge/... -count=1` 全部通过。
2. RAGFlow 合同测试覆盖上传、元数据、解析、状态、删除、超时、重定向、非零业务码、超大响应和网络错误。
3. 数据库测试证明批准事务只产生 1 个发布、1 个 Outbox、1 个 upsert 任务；同一幂等键重复执行不新增记录。
4. 状态机逐项拒绝非法跳转；草稿、待审核、驳回、下架、过期、删除和旧代次发布的可检索判定均为 false。
5. 权限测试中跨用户、跨空间、非管理员审批/激活/重试成功数为 0；未授权查询不泄露对象是否存在。
6. 隐私测试中未声明脱敏、SHA 不匹配、文件名含路径、manifest 含本地路径键、超限和不支持类型的服务端接收成功数为 0。
7. 审计测试确认任何事件均不包含文件正文、API Key、本地绝对路径；批准、驳回、失败、重试、激活、下架均有事件。
8. 特性开关关闭时知识导航数为 0、队列启动数为 0、知识路由成功响应数为 0，普通 FileBay 编译和既有关键测试保持通过。

## 人工验收闭环

1. 使用普通账号创建知识空间，确认生成的仓库为私有且空间与仓库一一绑定。
2. 上传一个客户端脱敏的 Markdown/PDF，页面显示 SHA-256、策略版本、Git 修订和“草稿”。
3. 提交审核后普通账号不能审批；另一个管理员批准后出现唯一索引任务。
4. 对接固定 `v0.26.4` RAGFlow 环境，确认实际上传、元数据、解析调用成功且 API Key 未出现在浏览器网络响应和日志中。
5. RAGFlow 解析完成后页面显示“待评测”；管理员激活后才显示“已发布”。
6. 下架后刷新页面立即不再显示当前发布，随后 RAGFlow 文档被删除；重复删除不报业务错误。
7. 临时停止 RAGFlow，任务进入可解释的失败/重试状态，普通 FileBay 仓库浏览、提交和登录不受影响。

## 投产阻断项

- 未提供真实 RAGFlow 地址、独立写入密钥、数据集映射和固定镜像 digest。
- 未完成目标部署的 TLS、备份恢复、恶意文件、查毒、资源配额、删除传播和漏洞扫描。
- 普通用户仍能直接访问 RAGFlow 管理界面/API Key，或能够绕过受控知识提交修改生产索引来源。
- 任一隐私、越权、引用追溯或回退测试失败。
