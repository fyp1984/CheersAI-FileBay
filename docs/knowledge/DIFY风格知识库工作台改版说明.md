# FileBay 企业知识库工作台改版说明

## 1. 改版目标

将当前“把所有能力罗列出来”的后台表单页，调整为面向业务人员的知识库工作台。用户进入后只需要回答两个问题：

1. 我现在要找资料，还是要把资料入库？
2. 如果要入库，当前该完成哪一步？

界面风格参考 Dify 的知识库，而非复制其视觉资产：采用克制的浅色工作台、清晰层级、列表优先、主操作突出、配置按需展开。保留 FileBay 的品牌、仓库、账号、团队和治理能力。

## 2. 对 Dify 的拆解结论

本次参考的是本地 Dify 知识库模块的页面组织与组件行为：

| Dify 特征 | 解决的问题 | FileBay 的落地方式 |
| --- | --- | --- |
| 列表页是默认入口，创建是明确的单独动作 | 用户先看到已有资源，而不是先面对配置 | 工作台先展示“查找资料”“提交资料”和管理员待办入口；空间与文档详情进入台账查看 |
| 创建、连接外部知识库采用独立路径 | 不让复杂配置打断日常浏览 | 资料入库采用五步向导；数据库接入移至管理员“高级接入” |
| 标题、简短说明、一个主操作组成页头 | 用户知道当前页面目的和下一步 | 每一页使用“页面标题 + 一句话 + 主按钮/状态” |
| 筛选、搜索、标签服务于列表，而非堆在表单内 | 降低阅读与决策成本 | 台账用卡片/列表呈现，筛选信息折叠在管理视图 |
| 默认仅显示必填项，高级设置按需展开 | 避免非技术人员填写技术字段 | 业务员页面只填名称、分类、来源；密级、责任人等采用默认策略或管理员审核补充 |
| 权限决定入口可见性 | 不让没有权限的用户误入管理页 | “治理中心”“数据库接入”“Dify 授权”仅管理员可见 |

## 3. 当前问题

1. 左侧导航按系统模块划分，但资料入库实际按业务流程推进；用户必须自己判断点击顺序。
2. 同一页面同时出现工作台、台账、接入、审核和授权，阅读负担过大。
3. 原生下拉框、输入框和卡片缺少统一的尺寸、留白、状态与帮助层级，视觉上像临时管理表单。
4. 仓库选择、来源登记、文档版本、审核规则的技术复杂度没有分层，业务人员不知道哪些必须填、哪些由系统处理。
5. 每步提交后回到总页会打断任务；用户看不到当前完成到哪里。

## 4. 信息架构与任务顺序

### 4.1 普通业务人员

```text
工作台
├─ 查找资料
└─ 提交资料
   ├─ 1. 选择或创建知识空间
   ├─ 2. 描述资料来源
   ├─ 3. 从 FileBay 仓库选择脱敏文件
   ├─ 4. 提交审核（系统接管）
   └─ 5. 查看发布结果
```

### 4.2 知识管理员

```text
治理中心
├─ 待办：来源启用、六项审核、发布/下架
├─ 知识台账：空间、文档、版本、状态
├─ 数据接入：仅 MySQL 脱敏只读视图
└─ 应用授权：Dify 固定空间与密级上限
```

## 5. 视觉与组件规范

### 页面骨架

- 内容最大宽度约 1180px，主内容优先；左侧仅保留两组简短导航。
- 页面背景使用 FileBay 现有浅色主题，卡片白底、细边框和 10–12px 圆角；不引入 Dify 的品牌色或字体。
- 顶部页头包含：标题、结果/说明、右侧唯一主操作。避免在同一首屏摆放三张同权重的操作卡。

### 表单

- 标准输入高度 40px，统一圆角、边框和聚焦态；下拉框使用与输入框一致的视觉规格。
- 每个字段使用“业务名称 + 一句说明 + 示例”。帮助文字在字段下方，技术字段不直接暴露给业务用户。
- 一屏只呈现当前步骤的 2–4 个必填项；版本关系、保留规则、技术引用进入“高级设置”或管理员处理。
- 必填项只用红色星号，不把所有字段都标为必填；提交按钮明确描述结果，例如“提交并进入审核”。

### 状态与反馈

- 使用状态徽章表达“待补充、等待审核、处理中、已发布、已下架”。
- 页面顶部显示简短的当前步骤提示；成功后跳转至下一步，并保留成功反馈。
- 空状态给出一个动作，不给一整块术语说明。

## 6. 本轮实施范围

1. 重构知识库工作台首页、左侧导航、检索页、提交资料流程与管理员待办的视觉层级。
2. 将“提交资料”改为单一路径的分步工作流；从仓库选择文件保持默认，保留本地上传为折叠备用能力。
3. 将数据库接入和 Dify 授权收纳在管理员治理入口，业务用户不再看到技术字段。
4. 统一输入框、下拉框、按钮、卡片、状态条和帮助文本样式。
5. 不改变现有接口、权限、审核规则、数据模型或 RAGFlow/Dify 集成边界。

## 7. 验收标准

- 新用户在首页能在 5 秒内找到“查找资料”和“提交资料”。
- 业务人员提交资料时，不需要理解密钥引用、字段映射、版本关系或六项审核细节。
- 每次提交成功后进入下一个业务步骤，而不是回到总工作台。
- 管理员仍能完成来源启用、审核、索引发布、数据库接入及 Dify 授权。
- 手机和窄屏下导航不遮挡主操作，表单保持单列可填写。
